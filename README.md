# Linux
Day 1(Basic Commands)

cd => Change directory
pwd => Print working directory
echo => to print #echo "Hello, Linux"
echo "Hello, Linux" > file.type to save in a file
cat => to read a file

date => Show date and time
date +%F => yyyy-mm-dd
cal => show current month as calendar
expr => for calculation # expr 1 + 2 or expr 3 \* 2
figlet => builds large letters from ordinary terminal characters. Run it with a short word

clear => clear screen
ls => list items

whoami => show current user
id or id root => check userid, group id etc
